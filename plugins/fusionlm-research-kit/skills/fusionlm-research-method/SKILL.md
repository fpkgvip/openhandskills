# Scientific mechanism research

Use this skill to guide reasoning, not to start a campaign. Read `references/FUSIONLM_CONTEXT.md` when the task concerns this project and `references/HYPOTHESIS_CARD.md` when recording candidates. Use `references/RESEARCH_SEEDS.md` as a starting map, not an exhaustive reading list.

1. Define entities first: task, attempt, round, accepted change, gate, escalation, context write, receipt and reservation. Do not interchange them.
2. Identify an observation and at least one competing explanation. Mark historical evidence and version.
3. Explain a causal intervention: what expensive work disappears, what information must remain, and what new work is introduced?
4. Derive a prediction AND a counterprediction. Specify a comparison that could distinguish them.
5. Use the cheapest valid evidence tier: primary source, code/test inspection, offline replay, synthetic probe, small paid screen if access permits, then untouched validation.
6. Challenge the preferred mechanism. A negative trial rejects that configuration under those conditions; it is not a proof of universal impossibility. A competitor result establishes a precedent, not replication in FusionLM.
7. Record keep/revise/reject/unresolved decisions and complexity rent. Account for runtime AND maintenance, latency, security, install and user burden.

Investigate a portfolio, not just one favourite architecture. Persistent sidekicks, routing, cascading, critique/revision, retrieval and context shaping operate at different levels and may compose or substitute for each other. Test interactions only after promising individual mechanisms emerge.

A quality gate is not an oracle. Passing checks are evidence about covered behaviour. Model agreement, self-confidence and a successful final message do not establish correctness.

Do not add reported savings percentages. Do not use an assumptions grid as a probability distribution. Separate product-feasibility hypotheses from evidence of current performance.

Use relevant built-in code-review and memory skills where present; do not assume they are enabled, authenticated or an independent reviewer. A role-switched self-review must be labelled as such.
