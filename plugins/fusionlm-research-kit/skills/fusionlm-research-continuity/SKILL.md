# Durable work, not a magical never-stop instruction

These skills do not supply a main assignment or guarantee runtime. Use the current user's actual task and available OpenHands continuation features. Do not start research solely because this pack was installed.

At campaign start create a small durable working directory using `references/STATE_TEMPLATE.md`. Maintain source, hypothesis, experiment and spending records, plus exact next actions. Keep a short index in repository memory rather than copying every source into AGENTS.md.

After each meaningful operation: save evidence, update status, reconcile active tasks/spend and choose the next authorised action. A finished child/memo/source search is not parent completion.

A practical state set: PREPARING, RUNNING, WAITING, AWAITING_INPUT, BLOCKED, COMPLETE, STOPPED_BY_OWNER. Temporary missing access blocks that operation, not the whole investigation. Do useful offline work while possible.

Before context handoff record: objective, branch/version, evidence IDs, hypotheses, unresolved contradictions, next executable actions, pending process/request IDs, budget state and wake trigger. On resume read the state before repeating work or launching duplicates.

Use actual scheduling/supervision if supported and authorised; never claim a future wake was registered without a successful operation. Do not provision platform automation/admin access from a skill merely because it exists in the public registry. Respect user stop and host limits.

For an assigned ~12-hour programme, spend time on substantive source chains, prototype construction and falsification—not repeated reports, idle waiting or commit counts. Document actual work and reused material honestly. Early completion needs satisfied evidence gates; missing paid access is not proof of impossibility.

Finish with accessible artifacts, exact execution/evidence labels, spend reconciliation, untested cases and the strongest supported recommendation. No claim of working in the background after an unresumable stop. No final “done” while authorised useful work remains unless genuinely blocked and checkpointed.
