# Built-ins and registry awareness

OpenHands has public skills such as code-review, code-simplifier, agent-memory, add-skill, skill-creator, uv, npm, github and openhands-sdk. These are catalog examples, not a guarantee they are loaded in this conversation. Inspect available skills first. Keep fusionlm-* names unique; do not override them.

The current public `research-brief` skill is a recurring Tavily + Notion publishing automation, not a general Brave-only research workflow. Do not trigger it and then ask for those extra accounts. `evidence-based-citations` has an exact official-source four-field format for particular requests; it is not a reason to exclude practitioner evidence from discovery.

Do not install a browser/MCP merely because it appears in a catalog. Existing browser/HTTP tools may already suffice. A public skill is guidance, not a new permission or executable tool. Registration may require a new conversation and may not be changeable from inside the current agent.
