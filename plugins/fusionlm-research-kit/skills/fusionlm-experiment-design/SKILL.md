# Experiments that answer a question

Use `references/EXPERIMENT_CARD.md` and `references/CAUSAL_PITFALLS.md`.

1. State the mechanism and rival explanation before collecting results.
2. Start with a source/offline/synthetic probe when it can isolate the issue. For a host backgrounding hypothesis, an identical delayed MCP result can separate host delivery from variable worker work.
3. Freeze model IDs, effort, client/product version, task/env, permissions, network/contamination policy, accounting and stopping rule. Change the minimum necessary factor.
4. Use independent sessions/repos. Never solve one arm then give the other its conversation, solution or grader feedback. Match and count cold/warm setup fairly.
5. Validate starting environments and distinguish baseline failures from introduced regressions. Keep held-out checks and reference solutions outside writable agent scope; consider test hooks/runtime/parser influence, not only file permissions.
6. Include every failure, retry, quota interruption and takeover. Do not rescue only the treatment. Use all relevant lead/worker/critic calls in workflow cost and count evaluation-only calls separately.
7. Measure acceptance, severe defects, latency and intervention as well as the targeted token/turn mechanism. Heuristic tampering warnings are not correctness proof.
8. Use small screens for mechanism discovery; untouched holdouts for validation. Revising a detector against known probes converts them into regression tests, not independent evidence of recall.

Do not launch paid model work without available credentials and the authorised remaining all-in allowance. Only a Brave key is currently guaranteed. Continue fixtures/prototypes/protocol preparation instead of stopping everything or claiming live results.

Choose sensible reversible local decisions without asking for each tool/test. Product deployment, permission expansion, purchases and production/account changes are not ordinary lab work.

Use synthetic secrets and disposable repositories. Collect raw API bodies only with a justified need and local restricted storage; do not publish them. No live model run is executed merely by invoking this skill.
